# Ahmed Elshal Academic Website

This is a fully static academic website. It has no paid plugins, no database, no tracking, and no platform branding.

## Included pages

1. Home
2. Research
3. Publications
4. About

## Publish free with GitHub Pages

1. Create a free GitHub account.
2. Create a new public repository named `yourusername.github.io`.
3. Upload every file and folder from this package to the repository.
4. Open the repository Settings.
5. Select Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select the `main` branch and the root folder.
8. Save.
9. Your site will appear at `https://yourusername.github.io`.

## Before publishing

1. Replace `assets/profile-placeholder.svg` with your real professional photo. Keep the same filename, or update the image path in `index.html` and `about.html`.
2. Add your exact Google Scholar, LinkedIn, and ResearchGate URLs.
3. Review publication status before launch.
4. Add a PDF CV only when you are comfortable making it public.

## Local preview

Double click `index.html`, or run a local static server in this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
